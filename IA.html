Uso de inteligencia artificial

Durante la realización del proyecto se utilizó inteligencia artificial como herramienta de apoyo.

Prompt utilizado Herramienta Qué obtuve Qué modifiqué
Actúa como desarrollador web front-end. Necesito crear la página principal de una plataforma educativa para niños menores de 10 años. ChatGPT Una estructura inicial para index.html. Modifiqué los textos, enlaces y estructura.
Crea un CSS para una página infantil usando variables CSS, Flexbox y CSS Grid. ChatGPT Una propuesta de estilos. Cambié colores, tamaños y distribución.
Haz que el catálogo de cuatro cursos sea responsive usando CSS Grid. ChatGPT Código para organizar las tarjetas. Ajusté los tamaños para celular y tablet.
Ayúdame a agregar accesibilidad a una página HTML para que pueda utilizarse con teclado y lector de pantalla. ChatGPT Recomendaciones sobre ARIA, alt y navegación. Agregué etiquetas semánticas y atributos ARIA.
Crea un JavaScript sencillo para un menú móvil con aria-expanded. ChatGPT Código para abrir y cerrar el menú. Lo adapté a las clases utilizadas en mi proyecto.

Mi aprendizaje

La inteligencia artificial fue utilizada como apoyo para comprender y construir partes del proyecto. El código fue revisado y modificado para adaptarlo a las necesidades de MiniAcad.
